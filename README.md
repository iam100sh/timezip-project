# timezip

**버스 기다리는 시간을 동네 시간으로.**
목적지를 치면 타야 할 버스를 찾아 주고, 그 버스가 오기 전까지 정류장 근처에서 **다녀올 수 있는 곳**을 추천해 주는 웹 서비스예요.
참빛설계학기(26-2) 팀 프로젝트입니다.

- 사이트: https://timezip-three.vercel.app
- 저장소: https://github.com/iam100sh/timezip-project (비공개)

---

## 무엇을 할 수 있나요

1. **출발지 → 목적지 버스 길찾기 (첫 화면)**: 출발지(비우면 내 위치)와 목적지를 치면, 출발지 400m 안 정류장들에서 **한 번에 가는 버스**를 찾아 걸어가서 탈 수 있는지까지 따져 **빨리 도착하는 순**으로 추천해요. 추천을 누르면 바로 "기다리는 동안 다녀올 곳"으로 이어져요. 환승은 카카오맵 대중교통 길찾기로 연결해요.
1. **정류장 보기**: 지도에 주변 버스정류장(서울 + 경기)이 떠요.
2. **목적지 → 타야 할 버스**: 정류장을 누르고 "어디 가세요?"에 목적지를 치면, 그 정류장에서 **한 번에 가는 버스**만 골라서 어디서 내리는지 보여 줘요.
3. **실시간 도착 정보**: 곧 오는 순, 몇 정거장 전, 막차·저상·혼잡·빈자리(경기 좌석버스) 표시, 30초마다 자동 새로고침.
4. **기다리는 동안 다녀올 곳**: 버스를 고르면 `남은 시간 − 복귀 여유 2분` 안에 **가는 시간 + 머무는 시간 + 오는 시간**이 들어오는 곳만 보여 줘요.
   - 분류: 먹거리 · 쇼핑 · 뷰티 · 생활 · 놀거리 (+ 세부 분류)
   - 가게마다 도보 **가는 길 / 돌아오는 길** (카카오맵 연결)
   - 시간 직접 정하기 슬라이더 (3~60분)
5. 그 밖에: 장소·주소 검색, 내 위치, 카테고리 버튼(카페·음식점·편의점·약국·병원·주유소·주차장), 지도 위 가게 아이콘을 누르면 가게 정보

## 파일 구조

```
timezip-project/
├── index.html      ← 화면 전부 (HTML + CSS + JavaScript가 한 파일에 있어요)
├── api/bus.js      ← 서버 함수: 서울시·경기도 버스 API 중간 서버 (인증키를 숨기려고 있어요)
├── api/tmap.js     ← 서버 함수: TMAP 보행자 경로 · 대중교통(환승) 경로
├── dev-server.js   ← 내 컴퓨터에서 테스트할 때 쓰는 서버 (Vercel에는 안 올라가요)
├── vercel.json     ← Vercel 설정 (서버 함수를 서울 지역에서 실행)
├── .env.example    ← 인증키 파일 예시
└── README.md       ← 이 문서
```

### 어떻게 연결되어 있나요

```
브라우저 (index.html)
 ├─ 카카오 지도 JavaScript API ── 지도, 장소 검색 (키가 페이지에 들어가도 괜찮은 키예요)
 └─ /api/bus (api/bus.js) ─────── 서울시 버스 API (ws.bus.go.kr)
                               └── 경기도 버스 API (apis.data.go.kr/6410000)
```

`/api/bus`에서 쓰는 주소:

| 주소 | 하는 일 |
|---|---|
| `/api/bus?type=nearby&lat=..&lng=..&radius=500` | 주변 정류장 (서울 + 경기 합침) |
| `/api/bus?type=arrivals&id=..&arsId=..&seoul=1&gg=1` | 정류장의 버스와 도착 정보 |
| `/api/bus?type=route&routeId=..` | 노선이 지나는 정류장 목록 (목적지 찾기용) |

## 내 컴퓨터에서 실행하기

### 1. 준비물
- **Git**: Mac은 터미널에서 `git --version`을 쳐 보고, 없으면 설치하라는 창이 떠요.
- **Node.js** (18 이상): https://nodejs.org 에서 LTS 버전을 설치해요.
- **GitHub 계정**: 저장소 초대를 받아서 수락해 두세요.

### 2. 코드 내려받기
```bash
git clone https://github.com/iam100sh/timezip-project.git
cd timezip-project
```
처음이면 GitHub 로그인 창이 떠요. GitHub CLI(`gh auth login`)나 GitHub Desktop을 써도 돼요.

### 3. 공공데이터 인증키 넣기
버스 기능을 쓰려면 공공데이터포털 인증키가 필요해요. (지도와 장소 검색은 키 없이도 돼요)

1. https://www.data.go.kr 에 가입하고 아래 **5개 서비스**를 각각 **활용신청**해요. 보통 바로 승인되고, 반영까지 몇 분에서 1시간쯤 걸려요.
   - 서울특별시_정류소정보조회 서비스
   - 서울특별시_노선정보조회 서비스
   - 경기도_정류소 조회
   - 경기도_버스도착정보 조회
   - 경기도_버스노선 조회
2. 마이페이지에서 **일반 인증키(Decoding)**를 복사해요. 끝이 `==`인 키예요.
3. `.env.example`을 복사해서 `.env` 파일을 만들고 키를 넣어요.
   ```bash
   cp .env.example .env
   ```
   ```
   BUS_API_KEY=여기에_내_인증키
   TMAP_APP_KEY=팀_TMAP_앱키
   ```
   - `TMAP_APP_KEY`는 SK open API의 팀 앱(timezip) **앱키(appKey)** 탭에 있어요. 팀 앱 멤버면 볼 수 있어요.
   - TMAP 무료 한도: **대중교통 하루 10건**(팀 전체 합산!), 보행자 경로 하루 1,000건. 대중교통은 꼭 필요할 때만 눌러 주세요.

> ⚠️ `.env`는 **절대 GitHub에 올리지 마세요.** `.gitignore`에 들어 있어서 보통은 안 올라가요.

### 4. 실행
```bash
node dev-server.js
```
브라우저에서 **http://localhost:8080** 을 열어요.
포트는 꼭 **8080**이어야 해요. 카카오 지도에 `http://localhost:8080`만 등록되어 있어서, 다른 포트에서는 지도가 안 떠요.

- `index.html`을 고쳤으면 브라우저를 새로고침하면 돼요.
- `api/bus.js`를 고쳤으면 서버를 껐다가(`Control + C`) 다시 켜요.

## 작업을 올리는 방법 (중요)

`main` 브랜치에 들어간 코드는 **자동으로 실제 사이트에 배포**돼요. 그래서 바로 `main`에 올리지 말고 **브랜치 → Pull Request(PR)** 순서로 해 주세요.
(Vercel 무료 요금제는 저장소 주인이 아닌 사람이 올린 코드의 자동 배포를 막을 수 있어서, 주인(@iam100sh)이 PR을 합치는 방식으로 배포해요.)

```bash
# 1. 최신 코드 받기
git checkout main
git pull

# 2. 내 작업용 브랜치 만들기 (이름은 하는 일로)
git checkout -b feature/영업시간

# 3. 고치고 저장한 뒤 올리기
git add .
git commit -m "약국 영업시간 반영"
git push -u origin feature/영업시간
```

4. GitHub 저장소 페이지에 뜨는 **Compare & pull request**를 눌러 PR을 만들어요. 무엇을 바꿨는지 짧게 적어 주세요.
5. Vercel이 PR마다 **미리보기 주소**를 만들어 줘요. (PR 아래 댓글에 링크가 달려요)
   - 미리보기 주소에서는 카카오 도메인 등록이 안 되어 있어서 **지도가 안 뜰 수 있어요.** 확인은 내 컴퓨터(localhost:8080)에서 해 주세요.
6. 주인이 확인하고 **Merge**하면 1분쯤 뒤 https://timezip-three.vercel.app 에 반영돼요.

## 바꿔 볼 만한 값들 (`index.html`)

| 이름 | 지금 값 | 뜻 |
|---|---|---|
| `BUFFER_MIN` | 2 | 버스 오기 전에 정류장에 돌아와 있을 여유 (분) |
| `WALK_M_PER_MIN` | 67 | 걷는 속도 (1분에 몇 m, 67 = 시속 4km) |
| `DETOUR` | 1.3 | 실제 길이 직선거리보다 몇 배 길다고 볼지 |
| `MAX_RADIUS` | 1000 | 다녀올 곳을 찾는 최대 거리 (m) |
| `GROUPS` | – | 분류(먹거리·쇼핑…)와 업종별 **머무는 시간** |
| `SOURCES` | – | 각 분류를 카카오에서 어떻게 찾을지 (분류 코드 / 키워드) |
| `DEST_RADIUS` | 500 | 목적지에서 몇 m 안의 정류장에 내리면 "간다"로 볼지 |
| `MIN_PER_STOP` | 2 | 한 정거장에 몇 분으로 탑승 시간을 어림할지 |
| `MAX_STOPS` | 35 | 이보다 많이 가야 하면 너무 돌아가는 걸로 보고 뺌 |
| `AUTO_REFRESH_MS` | 30000 | 도착 정보 자동 새로고침 간격 (밀리초) |
| `TRIP_STOP_RADIUS` | 400 | 버스 길찾기: 출발지에서 몇 m 안 정류장까지 확인할지 |
| `TRIP_MAX_STOPS` | 8 | 버스 길찾기: 가까운 정류장 몇 곳까지 확인할지 (API 사용량) |

## 알아 둘 점

- **API 사용량**: 공공데이터 개발용 키는 서비스마다 하루 약 1,000번까지예요. 테스트할 때 자동 새로고침을 오래 켜 두면 금방 써요.
- **정류장 번호는 서울·경기가 겹쳐요.** 그래서 정류장은 번호(arsId)가 아니라 **정류장 ID**로 구분해요. 서울 ID는 1, 경기 ID는 2로 시작해요.
- **환승 경로는 TMAP 대중교통**으로 찾아요. 무료가 하루 10건이라 "🔁 환승 경로 찾기" 버튼을 누를 때만 부르고, 같은 구간(약 100m 단위)은 하루 동안 저장해서 다시 써요.
- **영업시간은 아직 반영 안 했어요.** 카카오 공식 API가 영업시간을 주지 않아요. 약국은 공공데이터(국립중앙의료원)로 할 수 있어요.
- 카카오맵·네이버지도 화면을 자동으로 긁어 오는 방식(크롤링)은 이용약관 위반이라 쓰지 않아요.
